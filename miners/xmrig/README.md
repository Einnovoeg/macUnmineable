The source repository does not commit a prebuilt XMRig binary.

For local development, `install_xmrig.sh` downloads the official macOS arm64
release from the XMRig project into this directory, and the native app can also
auto-install it on first launch.

License for XMRig remains with the original authors and is documented in the
repository-level `THIRD_PARTY_NOTICES.md`.
