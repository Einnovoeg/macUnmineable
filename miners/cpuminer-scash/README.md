# cpuminer-scash runtime directory

This folder is where the official `cpuminer-scash` macOS arm64 binary is staged
for local app builds and runtime use.

The source repository intentionally does not commit the downloaded binary.
Install or update it with:

```bash
./scripts/install_cpuminer_scash.sh
```

License for `cpuminer-scash` remains with the original upstream authors and is
documented in the repository-level `THIRD_PARTY_NOTICES.md`.
